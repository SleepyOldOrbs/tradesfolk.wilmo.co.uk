```yaml

```

Key decisions per research:
- `disable-model-invocation: true` — this is a user-triggered reference card, not something Claude should auto-invoke (Claude should use assemble-team for active recommendations)
- `argument-hint: scenario name` — plain text, no brackets (avoids YAML parsing bug)
- No `user-invocable` field — defaults to `true`
- No snake_case fields anywhere

**Body:**

Write the body as instructions to Claude. Start with a brief instruction line about presenting templates and filtering by `$ARGUMENTS` if provided. Then list 7 templates in a numbered heading format. Each template should have:

Use these exact 7 compositions (from CONTEXT.md locked decisions):

   - Agents: react-specialist, javascript-developer, qa-tester

   - Agents: security-auditor, backend-architect, devops-engineer
   - Lead: security-auditor
   - When to use: Security review, vulnerability remediation, and infrastructure hardening.

4. **Frontend Overhaul**
   - Agents: react-specialist, ux-designer, javascript-developer
   - Lead: react-specialist

7. **Documentation Sprint**
