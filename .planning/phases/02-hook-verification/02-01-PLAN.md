  <action>
Rewrite hooks/teammate-checklist.sh with these exact changes:

1. Change shebang from `#!/bin/bash` to `#!/usr/bin/env bash` (per user decision -- portable across NixOS, macOS Homebrew bash, etc.)

2. Replace the jq-based JSON extraction (per user decision -- remove jq dependency entirely):
   - OLD: `TEAMMATE_NAME=$(echo "$INPUT" | jq -r '.teammate_name // "unknown"' 2>/dev/null)`
   - NEW: Use grep+sed pipeline (per research recommendation):
     ```
     TEAMMATE_NAME=$(echo "$INPUT" | grep -o '"teammate_name"[[:space:]]*:[[:space:]]*"[^"]*"' | sed 's/.*:.*"\([^"]*\)"/\1/')
     ```
   - The grep pattern extracts the full `"teammate_name": "value"` pair using POSIX character classes (`[[:space:]]` not `\s`) for BSD/GNU compatibility
   - The sed pattern extracts just the value portion

3. Add explicit fallback (per user decision -- use "unknown" if parsing fails):
   ```
   if [ -z "$TEAMMATE_NAME" ]; then
     TEAMMATE_NAME="unknown"
   fi
   ```

4. Keep ALL existing behavior unchanged:
   - Read stdin with `INPUT=$(cat)`
   - Log to stderr: `echo "[agent-pool] Teammate ${TEAMMATE_NAME} going idle" >&2`
   - Exit 0 (allow idle, non-blocking)
   - Keep all existing comments (update the "Extract teammate info" comment to explain the grep+sed approach)

5. Do NOT add `set -euo pipefail` (per research recommendation -- would break fallback logic since grep returns exit code 1 on no match, which would abort the script before reaching the fallback)

6. Do NOT rename the file (per research recommendation -- teammate-checklist.sh describes purpose, not event name)

The final script should be approximately 22-25 lines, matching the research-recommended implementation almost exactly.
